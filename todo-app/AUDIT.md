## Non-blocking observations (no action taken)

1. **Non-atomic writes** — `save()` writes the JSON store in place; a crash mid-write could truncate it. A tmp-file + `os.replace()` would harden it.
2. **Naive timestamps** — `datetime.now()` records local time without timezone info in the `created` field.
3. **Uncovered paths** — tests don't exercise ambiguous id prefixes, `undo` on a missing id, or `clear-done` when nothing is done (all behave sensibly per code reading, just untested).
4. **Stale docstring** — `test_todo.py` says to run via `python3 -m unittest`, though pytest is the actual runner in this repo.
5. **Error handling is sound** — `load()` tolerates a missing/corrupt store; `find()` distinguishes unknown vs. ambiguous id prefixes; CLI maps `ValueError`/`KeyError` to exit code 1.

## Conclusion

The app is in a healthy state: 13/13 tests green, no compile issues, no changes needed.
